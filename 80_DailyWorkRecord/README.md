# Daily Work Record

tags: #daily-work #execution-log #vault-management

## Purpose

此目錄保存 Vault 每日實際工作的可追溯紀錄，回答「今天依序做了什麼、為何這樣整理、哪些知識檔受到影響，以及還留下哪些後續工作」。

Daily Work Record 不取代 Source Note、Concept、Map、Questions 或 REVIEW；它只記錄工作過程並連回正式知識成果。

## Naming

```text
YYYY-MM-DD.md
```

同一天的後續工作附加到同一份紀錄。

## Required Structure

```markdown
# YYYY-MM-DD Daily Work Record

## Goals
## Step-by-step Record
### Step 1 — ...
### Step 2 — ...
## Affected Knowledge Files
### 03-Concepts
### 04_Maps
### 05_Questions
### 06_review
## Relationships Persisted
## Validation
## Follow-up
```

每一步應記錄：輸入／檢查範圍、判斷、動作、輸出與驗證。不要只寫「完成整理」。
