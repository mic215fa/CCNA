# Daily Work Review

tags: #daily-review #review-map #vault-management

## Purpose

此目錄將每日新增或重整的知識轉成可執行的複習路徑。每個 review unit 約 15 分鐘，由 Source evidence 前進到 Concept mechanism，再到 Map relationship 與 troubleshooting reasoning。

## Naming

```text
YYYY-MM-DD Review Map.md
```

## Fifteen-minute Unit

每一單元包含：

1. **Goal**：本單元應能解釋什麼。
2. **Read**：少量 Sources、Concepts 或 Maps。
3. **Recall**：關閉筆記後自行重建機制或比較。
4. **Verify**：用 reasoning question 或 troubleshooting case 驗證。
5. **Output**：一句結論、簡圖、比較表或排錯順序。

## Review Order

```text
Source evidence
  ↓
Core Concept
  ↓
Mechanism / contrast
  ↓
Knowledge Map
  ↓
Questions and REVIEW
```

若時間不足，Daily Review 應另外標示 priority path，而不是要求一次完成全部內容。
