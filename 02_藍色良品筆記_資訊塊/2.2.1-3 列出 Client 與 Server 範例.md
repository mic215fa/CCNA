# 2.2.1-3 列出 Client 與 Server 範例

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#2.2.1-3 列出 Client 與 Server 範例|2.2.1-3 列出 Client 與 Server 範例]] 拆出。

## 原文內容

Let's list a few examples of client-server pairs:

- Client-A network-enabled TV that streams a movie on Netflix
- Server-A Netflix server that hosts the movie and sends it over the network
- Client-An iPhone scrolling through X (formerly Twitter)
- Server-X servers that host the tweets and send them to the iPhone
- Client-A PC accessing an Excel spreadsheet located on an enterprise's server
- Server-An enterprise's server containing spreadsheets and other internal files

## 逐句繁體中文翻譯

- 接下來列出幾個 client-server pair 的例子。
- Client：可以連網的 TV，用來串流 Netflix 電影。
- Server：Netflix server，負責 hosting 該電影並透過 network 傳送。
- Client：正在滑 X（formerly Twitter）的 iPhone。
- Server：X servers，負責 hosting tweets 並傳送到 iPhone。
- Client：正在存取企業 server 上 Excel spreadsheet 的 PC。
- Server：存放 spreadsheets 與其他 internal files 的 enterprise server。
