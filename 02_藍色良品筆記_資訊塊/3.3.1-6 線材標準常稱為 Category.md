# 3.3.1-6 線材標準常稱為 Category

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#3.3.1-6 線材標準常稱為 Category|3.3.1-6 線材標準常稱為 Category]] 拆出。

## 原文內容

The standards for these cables are given names like Category 5, which is often shortened to Cat 5. Table 3.2 lists some cable standards that can be used with the aforementioned Ethernet standards.

Table 3.2 Common UTP cable standards
| Speed | Ethernet informal name | Cable name |
| :--- | :--- | :--- |
| 10 Mbps | 10BASE-T | Cat 3 |
| 100 Mbps | 100BASE-T | Cat 5 |
| 1 Gbps | 1000BASE-T | Cat 5e |
| 10 Gbps | 10GBASE-T | Cat 6a |

## 逐句繁體中文翻譯

- 這些線材標準會被命名為 Category 5 之類的名稱，通常會縮寫為 Cat 5。
- 表 3.2 列出一些可搭配前述 Ethernet 標準使用的線材標準。
- 表 3.2：常見 UTP 線材標準。
- 欄位包含：速度、Ethernet 非正式名稱、線材名稱。
- 10 Mbps 對應 10BASE-T，使用 Cat 3。
- 100 Mbps 對應 100BASE-T，使用 Cat 5。
- 1 Gbps 對應 1000BASE-T，使用 Cat 5e。
- 10 Gbps 對應 10GBASE-T，使用 Cat 6a。
