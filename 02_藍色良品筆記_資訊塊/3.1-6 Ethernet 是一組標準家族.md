# 3.1-6 Ethernet 是一組標準家族

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#3.1-6 Ethernet 是一組標準家族|3.1-6 Ethernet 是一組標準家族]] 拆出。

## 原文內容

Ethernet is not a single standard but rather a family of standards that define both physical aspects of network connections as well as how data should be formatted into messages to be sent over the network.

## 逐句繁體中文翻譯

- Ethernet 不是單一標準，而是一個標準家族。
- 這個標準家族同時定義網路連線的實體層面，以及資料應如何格式化成訊息並透過網路傳送。
