# 3.3.1-5 Ethernet 線材實際由 EIA 與 TIA 定義

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#3.3.1-5 Ethernet 線材實際由 EIA 與 TIA 定義|3.3.1-5 Ethernet 線材實際由 EIA 與 TIA 定義]] 拆出。

## 原文內容

NOTE The cables used in the aforementioned Ethernet standards are not actually defined by the IEEE but rather by two other organizations: the Electronic Industries Alliance (EIA) and the Telecommunications Industry Association (TIA). So the name "Ethernet cable" isn't very accurate because the cables, although used by Ethernet, are not defined by IEEE 802.3.

## 逐句繁體中文翻譯

- 注意：前述 Ethernet 標準所使用的線材，其實不是由 IEEE 定義的。
- 這些線材是由另外兩個組織定義：Electronic Industries Alliance（EIA）與 Telecommunications Industry Association（TIA）。
- 因此，「Ethernet cable」這個名稱並不是很精確，因為這些線材雖然被 Ethernet 使用，但不是由 IEEE 802.3 定義。
