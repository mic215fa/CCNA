# 2.2.2-1 Switch 讓連接設備彼此通訊

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#2.2.2-1 Switch 讓連接設備彼此通訊|2.2.2-1 Switch 讓連接設備彼此通訊]] 拆出。

## 原文內容

Devices connected to a switch are able to communicate with each other via the switch. Note that they do not typically communicate with the switch itself-the switch only serves as infrastructure over which communication can occur.

## 逐句繁體中文翻譯

- 連接到 switch 的設備，可以透過 switch 彼此通訊。
- 注意，它們通常不是和 switch 本身通訊。
- Switch 只是作為 infrastructure，讓通訊可以發生。
