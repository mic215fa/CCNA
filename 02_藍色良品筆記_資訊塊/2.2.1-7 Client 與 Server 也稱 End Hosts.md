# 2.2.1-7 Client 與 Server 也稱 End Hosts

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#2.2.1-7 Client 與 Server 也稱 End Hosts|2.2.1-7 Client 與 Server 也稱 End Hosts]] 拆出。

## 原文內容

Client and server nodes are often called endpoints or end hosts. These are general terms for devices that communicate over a network, as opposed to the network infrastructure devices that connect the end hosts.

## 逐句繁體中文翻譯

- Client 與 server nodes 常被稱為 endpoints 或 end hosts。
- 這些是指透過 network 進行通訊的設備。
- 它們不同於負責連接 end hosts 的 network infrastructure devices。
