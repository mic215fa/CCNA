# 2.2.4-3 Network Firewall 是獨立硬體設備

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#2.2.4-3 Network Firewall 是獨立硬體設備|2.2.4-3 Network Firewall 是獨立硬體設備]] 拆出。

## 原文內容

A network firewall is a separate hardware appliance that serves a purpose similar to a host-based firewall but on a larger scale. It inspects all traffic entering and exiting a network and decides to allow or deny it based on a set of configured rules.

## 逐句繁體中文翻譯

- Network firewall 是獨立的 hardware appliance。
- 它的目的類似 host-based firewall，但規模更大。
- 它會檢查進出 network 的所有 traffic，並根據一組 configured rules 決定允許或拒絕。
