# 1.1.1-0 CCNA 考試分成六大領域

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#1.1.1-0 CCNA 考試分成六大領域|1.1.1-0 CCNA 考試分成六大領域]] 拆出。

## 原文內容

The six domains tested on the CCNA exam and their relative weightings are as follows:

- 1.0 Network Fundamentals-20\%
- 2.0 Network Access-20\%
- 3.0 IP Connectivity-25\%
- 4.0 IP Services-10\%
- 5.0 Security Fundamentals-15\%
- 6.0 Automation and Programmability-10\%

## 逐句繁體中文翻譯

- CCNA 考試測驗的六大領域與相對比重如下。
- 1.0 Network Fundamentals（網路基礎）：20%。
- 2.0 Network Access（網路存取）：20%。
- 3.0 IP Connectivity（IP 連通性）：25%。
- 4.0 IP Services（IP 服務）：10%。
- 5.0 Security Fundamentals（安全基礎）：15%。
- 6.0 Automation and Programmability（自動化與可程式化）：10%。
