# 2.1-2 Node 是任何連上網路的設備

> [!info] 藍色良品筆記：資訊塊
> 本筆記由紅色資訊源 [[01_紅色良品筆記_資訊源/CCNA-V1-CH2-15_red_note#2.1-2 Node 是任何連上網路的設備|2.1-2 Node 是任何連上網路的設備]] 拆出。

## 原文內容

A node is any device that connects to a network. It includes the previously listed examples, like a personal computer or an iPhone, as well as the network infrastructure that
connects the devices-the routers, switches, firewalls, and various other types of devices that make up the network.

## 逐句繁體中文翻譯

- Node 是任何連接到 network 的設備。
- 它包含前面列出的例子，例如 personal computer 或 iPhone。
- 它也包含連接這些設備的 network infrastructure，例如 routers、switches、firewalls，以及組成 network 的各種其他設備。
