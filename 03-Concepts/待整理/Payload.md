# Payload

tags: #concept #acting-ccna #network-fundamentals

## Aliases

- 載荷

## Definition

Payload is the contents encapsulated inside a protocol data unit.

## Why It Exists

Payload describes the data a layer is carrying for the layer above it.

## Related Concepts

- [[Protocol Data Unit]]
- [[Encapsulation and De-encapsulation]]
- [[Header and Trailer]]

## Mechanism

- A frame's payload is a packet.
- A packet's payload is a segment.
- A segment's payload is application data.
