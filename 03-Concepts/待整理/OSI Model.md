# OSI Model

tags: #concept #acting-ccna #network-fundamentals

## Aliases

- Open Systems Interconnection reference model
- OSI reference model

## Definition

OSI Model 是 ISO developed 的 conceptual networking model，定義七個 layers。

## Why It Exists

它提供一套理解與討論網路功能的術語框架。雖然現代網路不使用 OSI 作為實際運作模型，但其 layer terminology 仍深刻影響網路領域。

## Mechanism

OSI layers：

1. Physical
2. Data Link
3. Network
4. Transport
5. Session
6. Presentation
7. Application
