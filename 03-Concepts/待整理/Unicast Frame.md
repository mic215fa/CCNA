# Unicast Frame

tags: #concept #acting-ccna #switching #layer2

## Definition

Unicast Frame 是目的地為單一 host MAC address 的 Ethernet frame。

## Why It Exists

大多數主機間通訊是一對一；unicast frame 讓 Layer 2 可以指定單一接收者。
