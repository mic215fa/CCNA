# Port Number

tags: #concept #acting-ccna #network-fundamentals #layer4

## Aliases

- Layer 4 port
- 通訊埠號碼

## Definition

Port Number is the Layer 4 addressing scheme used to send data to a specific application process on the destination host.

## Why It Exists

A destination host can run many applications at the same time; port numbers allow received network data to reach the correct application process.

- [[Transport Layer]]

## Related Concepts

- [[Application Layer]]
- TCP
- UDP

## Contrast

Layer 4 port number is not the same as a physical port on a device. Same word, different concept.

## Mechanism

In Chapter 4, HTTPS uses port 443. DNS, HTTP, and HTTPS each accept messages using different Layer 4 port numbers.
