# Multilayer Switch

tags: #concept #acting-ccna #switching #routing #vlan

> [!info] Concept role
> [[Inter-VLAN Routing]] 的實作方式：以 SVIs 在 switch 內部連接多個 VLAN/subnets。

## Definition

Multilayer Switch 是能同時執行 Layer 2 switching 與 Layer 3 routing 的 switch。

## Why It Exists

在 campus/LAN 內，不同 VLAN 間常需要快速 routing。Multilayer switch 可在 switch 內部完成 inter-VLAN routing，而不必依賴外接 router。

## Mechanism

啟用 `ip routing` 後，multilayer switch 可用 SVIs 代表各 VLAN 的 default gateway，並在 routing table 中加入 connected/local routes。

Host-to-host traffic 先在來源 VLAN 送往來源 SVI。Multilayer switch 解封裝 frame、查詢 routing table，再在目的 VLAN 建立新的 Ethernet frame。雖然 forwarding 發生在同一台設備內，Layer 2 header 仍會在 routing boundary 前後改變。

## Depends On

- `ip routing` 已啟用。
- 對應 [[VLAN]] 已存在。
- [[Switch Virtual Interface]] 設定正確的 IP address，並滿足 up/up 條件。
- Access/trunk topology 能把來源與目的 hosts 分別接到正確 VLAN。

## Trade-offs

- 優點：不需讓 campus 內部 traffic 繞到外接 router，並避免 ROAS 單一 trunk 集中所有 VLAN traffic。
- 限制：必須同時理解 Layer 2 VLAN state、SVI line protocol 與 Layer 3 routing table，排錯層次較多。

## Contrast With ROAS

- [[12.4-Router on a Stick]] 使用 router subinterfaces 與外部 trunk。
- Multilayer switching 使用內部 SVIs 作為 VLAN gateways；[[Routed Port]] 則可連接外部 Layer 3 network。
