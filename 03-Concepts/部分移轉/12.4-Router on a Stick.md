# Router on a Stick

tags: #concept #acting-ccna #vlan #routing

> [!info] Concept role
> [[Inter-VLAN Routing]] 的實作方式：以一個 router physical interface、trunk 與多個 subinterfaces 服務多個 VLAN。

## Aliases

- ROAS

## Definition

Router on a Stick 是一種 inter-VLAN routing 方法：router 用單一 physical interface 連接 trunk link，並透過多個 subinterfaces 分別服務不同 VLAN。

## Why It Exists

若每個 VLAN 都用一條 router physical interface，會消耗大量 router ports 與線材。ROAS 用一條 trunk link 承載多個 VLAN，讓 router 仍可在 VLAN 間 routing。

## Mechanism

Router physical interface 被分成多個 subinterfaces；每個 subinterface 設定 `encapsulation dot1q <vlan-id>` 與該 VLAN/subnet 的 IP address，作為該 VLAN 的 default gateway。

收到 tagged frame 後，router 依 802.1Q VLAN ID 將 frame 交給對應 subinterface，移除 Layer 2 encapsulation、執行 routing lookup，再由目的 VLAN 的 subinterface 建立新的 Ethernet frame。這表示 routing 發生在 subinterfaces 之間，而不是 trunk 自己跨 VLAN forwarding。

## Trade-offs

- 優點：節省 router physical interfaces，拓撲與設定容易理解。
- 限制：多個 VLAN 共用同一 physical link，頻寬與故障點集中。
- 依賴：switch port 必須為 trunk，各 VLAN 必須被允許，subinterface 的 dot1Q VLAN ID 必須對應正確。

## Contrast With

- [[12.4-Multilayer Switch]]：ROAS 讓 traffic 往返外接 router；multilayer switch 可在 switch 內部完成 VLAN 間 routing。
