# Computer Network

tags: #concept #acting-ccna #network-fundamentals

## Aliases

- 電腦網路
- Network

## Definition

Computer Network 是允許 [[Node]] 分享 [[Resource]] 的 telecommunications network。

## Why It Exists

它存在的目的，是讓多個設備不只是各自運作，而是能透過連線交換資料、使用服務、存取檔案或共享設備。
