# Octet

tags: #concept #acting-ccna #ipv4

## Definition

Octet 是 8 bits 的群組；IPv4 address 由四個 octets 組成。

## Why It Exists

把 32-bit IPv4 address 切成四個 8-bit chunks，可以讓 binary/decimal conversion 與 dotted decimal notation 更容易讀寫。

## Mechanism

每個 octet 可表示 0 到 255，因此 IPv4 dotted decimal notation 的每一段都是 0–255 的 decimal number。
