# Network Standard

tags: #concept #acting-ccna #network-fundamentals

## Aliases

- Standards
- 網路標準

## Definition

Network Standard 是一組技術需求與規格，用來定義網路中通訊的規則。

## Why It Exists

不同廠商、不同硬體、不同媒介要互通，必須遵守共同規則；否則就像兩個人使用不同語言或不同媒介溝通，訊息無法被理解。

## Mechanism

Network Standard 會規範：

- 資料如何格式化；
- 實體媒介如何連接；
- 設備在共同規則下如何互通。
