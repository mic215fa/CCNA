# Node

tags: #concept #acting-ccna #network-fundamentals

## Aliases

- 節點

## Definition

Node 是任何連接到網路的設備。

## Why It Exists

Node 這個概念讓我們能用同一個詞描述所有參與網路的設備，包含端點設備與網路基礎設施設備。

## Contrast

- [[End Host]]：End Host 通常指進行通訊的端點。
- [[Node]]：範圍更廣，包含端點與 network infrastructure devices。
