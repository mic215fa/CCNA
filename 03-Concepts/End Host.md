# End Host

tags: #concept #acting-ccna #network-fundamentals

## Aliases

- Endpoint
- 端點

## Definition

End Host 是在網路上進行通訊的端點設備，例如 PC、Server、Phone、Printer 等。

## Why It Exists

End Host 讓我們區分「通訊的端點」與「承載通訊的基礎設施設備」。

## Contrast

- End Host：使用網路進行通訊。
- Network infrastructure device：連接 End Hosts，讓通訊能發生，例如 [[Switch]]、[[Router]]、[[Firewall]]。
