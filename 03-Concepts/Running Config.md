# Running Config

tags: #concept #acting-ccna #configuration

## Aliases

- running-config

## Definition

Running Config 是 Cisco IOS device 目前正在使用、正在生效的設定檔，儲存在 RAM。

## Why It Exists

它讓設定命令能立刻改變設備行為，但也代表如果沒有儲存，reload 或斷電後變更會消失。
