# Terminal Emulator

tags: #concept #acting-ccna #cli

## Definition

Terminal Emulator 是在電腦上模擬傳統 terminal 的軟體，用來透過 console 連線存取設備 CLI。

## Why It Exists

PC 需要一個軟體來傳送文字命令、接收 CLI 輸出，才能管理 Cisco router 或 switch。
