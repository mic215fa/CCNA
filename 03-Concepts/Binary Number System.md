# Binary Number System

tags: #concept #acting-ccna #number-system

## Aliases

- Base 2
- 二進位

## Definition

Binary Number System 是只使用 0 與 1 兩個 digits 的數字系統。

## Why It Exists

電腦與網路底層以 bits 表示資料；理解 binary 是理解 [[IPv4 Address]]、[[Netmask]]、subnetting 與 many network fields 的基礎。

## Mechanism

Binary 每往左一位，位值乘以 2。8-bit binary number 可表示 0 到 255，共 256 種值。
