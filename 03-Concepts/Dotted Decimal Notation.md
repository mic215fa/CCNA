# Dotted Decimal Notation

tags: #concept #acting-ccna #ipv4

## Definition

Dotted Decimal Notation 是 IPv4 address 的常見表示法，把 32-bit address 分成四個 octets，並以 decimal numbers 與 dots 表示。

## Why It Exists

32-bit binary address 不易閱讀與記憶；dotted decimal 讓 IPv4 address 更適合人類操作。

## Example

```text
11000000.10101000.01100100.01100100
↓
192.168.100.100
```
