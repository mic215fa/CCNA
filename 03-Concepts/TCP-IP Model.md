## Definition

TCP/IP Model 是現代網路使用的 networking model，名稱來自其中兩個核心 protocols：Transmission Control Protocol（TCP）與 Internet Protocol（IP）。

## Why It Exists

它提供一個 practical framework，把 network communication 所需功能分層，讓多個 protocols 能共同完成從應用程式到實體媒介的通訊。
